# rex-toolkit
Rex’s Toolkit includes a Media Downloader intended only for downloading content you own, have permission to download, or that is legally available to save. Users are responsible for complying with platform terms of service and applicable copyright laws. This app does not bypass DRM, paywalls, login restrictions, or access controls.
